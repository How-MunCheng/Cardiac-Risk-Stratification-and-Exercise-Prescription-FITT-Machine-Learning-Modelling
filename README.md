# AI-ENABLED PERSONALIZED PRESCRIPTION RECOMMENDATION FOR CARDIAC REHABILITATION

## Project Overview
This repository contains machine learning pipelines for:
- Cardiac risk stratification
- Exercise prescription (FITT) prediction - Frequency, Intensity, Time, Type

## File execution order
Please run the code file in order:
01_risk_stratification
├──  01_data_preprocessing_and_feature selection
├──  02_machine_learning_modelling 
└──  03_generate_predicted risk

02_exercise_prescription(FITT)
├──   01_data_preprocessing_and_feature selection
└──   02_machine_learning_modelling

03_benchmarking
├──   01_data_preprocessing_and_feature selection
└──   02_machine_learning_modelling
   
## Components
- Data preprocessing and feature selection
- Machine learning modelling
- Benchmark modelling
- Predicted risk level generation

## ML Models Used
- Conventional models
- Ensemble models
- Deep learning models
- Transformer models

## Feature Selection Methods Used
- ANOVA F-test
- Mutual Information
- RFE with Logistic Regression
- RFE with Linear SVM
- LASSO
- Random Forest Feature Importance
